# Ranjeet Kumar Portfolio

A modern, dark-ish professional React portfolio for Ranjeet Kumar, based on the supplied resume and profile photo.

## Stack
- React
- Vite
- Framer Motion
- Lucide React
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite local URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Included
- Responsive portfolio
- Hero section with profile photo
- About
- Professional experience
- Projects with modal details
- Technical skills
- Education and recognition
- Contact section
- Resume download link
- Smooth scrolling and subtle animations

The resume PDF/DOCX is not generated by this package; place your preferred resume file in `public/` as `Ranjeet_Kumar_Resume.docx` if you want the Download Resume button to work.
